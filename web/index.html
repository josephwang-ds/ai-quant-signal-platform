SEC 8-K disclosures · point-in-time study

Which filings deserve a human read?

Forty 8-Ks land before breakfast and an analyst has time for five. This ranks them by how hard the market is about to react — magnitude, not direction. Predicting direction is a bet against desks with faster data. Predicting which disclosures matter is a triage problem, and triage is answerable.

The result that mattered was a bug

A pipeline written the obvious way reports an ROC AUC of 0.888 on real SEC filings. The version that survives its own audit reports 0.768. An AUC near 0.9 on public disclosures would be a remarkable finding. It is instead four bugs — and every one of them produced a better number.

What it does not claim

No return prediction. Direction is never modelled. No strategy return, Sharpe ratio or P&L appears anywhere in the repository.

Survivorship is not controlled on the real-data path. The demo universe is 200 hand-picked large caps that still exist, which is why the point-in-time universe row above does not move — 0.262916 before and after, to six decimals. That is the survivor sample confessing rather than hiding. That leak is measured on the synthetic corpus instead, where membership is generated with issuers that join and leave.

Daily bars only. The entry rule — first open at or after the decision time — is the most conservative convention available at that resolution.

Reproducing it

git clone https://github.com/josephwang-ds/ai-quant-signal-platform
cd ai-quant-signal-platform
python3 -m venv .venv && source .venv/bin/activate
make install
make demo            # synthetic, ~4 min, no credentials

export EDGAR_USER_AGENT="Your Name you@example.com"
make universe && make doctor && make ingest && make run

The synthetic path needs no SEC credentials and no network, and every report states in its own banner which of the two produced it.
