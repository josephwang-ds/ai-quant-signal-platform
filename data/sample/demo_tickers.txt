# US large- and mid-cap issuers for the demo ingest, spread across sectors.
#
# THIS IS NOT AN INDEX AND NOT POINT-IN-TIME. Every name here is a company that
# still exists and is still large today, which is the definition of a survivor
# sample. Survivorship bias is therefore NOT controlled on this data path -- see
# docs/LEAKAGE.md section 3. It is demonstrated on the synthetic corpus instead,
# where membership is generated with issuers that join and leave.
#
# Chosen for filing volume and sector spread, not for any expected result. The
# count matters for a different reason: the daily queue metric only means
# something when a session carries more filings than the queue length, and a
# universe this size puts roughly ten a session in front of the reader.
#
# Deliberately excludes issuers spun off in the last two years -- their price
# history is too short for the estimation window and every one of their events
# would be dropped.
#
# Unresolved tickers are reported by `make universe`, not fatal.
